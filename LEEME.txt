TUTORIAL DE DESARROLLO DE APLICACIONES MÓVILES

ARCHIVOS
- index.html: estructura y contenido base de la página.
- css/estilos.css: diseño visual y adaptación a computadora, tableta y celular.
- js/app.js: navegación entre temas, buscador, barra de progreso y biblioteca de videos.

CÓMO EJECUTAR
1. Descomprime la carpeta.
2. Abre index.html con Google Chrome, Microsoft Edge o Firefox.
3. No necesita instalar programas ni configurar una base de datos.
4. Para editar el proyecto, abre la carpeta en Visual Studio Code.

NOTAS
- El contenido está orientado principalmente a Android.
- Algunos fragmentos de código son ejemplos conceptuales y requieren completarse para formar una aplicación real.
- Las referencias están disponibles en el apartado final del tutorial.
- El apartado “Videos de apoyo” organiza búsquedas de videos de YouTube por cada tema.
